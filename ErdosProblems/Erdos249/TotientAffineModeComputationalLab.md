# Totient affine-mode obstruction

The pure-dyadic fixed-quotient error satisfies

`E_(H+1) = 2 E_H + phi(c+H+1) - k`.

If `E_H=A H+B` eventually, the recurrence forces the shifted totient letters
to be affine in `H`.  The cheapest exact falsifier uses two arbitrarily late
primes `2<p<q` and the doubled first prime.  Their totient graph points are

`(p,p-1)`, `(q,q-1)`, `(2p,p-1)`.

Their oriented affine determinant is exactly `-p(q-p)`, which is nonzero.
Thus the actual totient word cannot support an eventually affine endpoint
error for any basepoint `c` or fixed quotient `k`.

The symbolic computation and its source-bound receipt are generated by
`scripts/check_totient_affine_mode.py`.  The cofinal result is kernel-checked
in `TotientAffineModeEscape.lean` as
`not_eventuallyAffine_pureDyadicEndpointError`; the script is not being used
as proof authority.

This eliminates a structural part of the full linear-envelope obstruction,
not Erdős #249 itself.  A surviving permanent trap must have genuinely
non-affine linear-scale oscillation while still meeting the already checked
cofinal pre-prime bottom locks.  That composite-block propagation remains the
next analytic target.
