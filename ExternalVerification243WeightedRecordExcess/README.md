# Weighted LCM record excess

The Challenge defines the actual product-cleared numerator, cumulative LCM, overlap product, normalized numerator U and centered error V using only Mathlib. For a positive strictly increasing integer sequence with rational reciprocal sum and a(n+1)/a(n)^2 tending to one, eventual Sylvester recurrence is equivalent to summability of the excess (-V-B)+ times f(U) at strict U-record steps for some natural B. The weight is nonnegative and nonincreasing on [1,infinity), with divergent integral.

No abstract orbit, recurrence supplier, or normalized error estimate is a hypothesis. These are proved by the source theorem. This matches res:weightedrecord in the current paper. It does not establish the required summability from rationality alone and does not solve Erdős243.
