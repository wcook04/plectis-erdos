# Evidence records

Each of the sixteen Erdős papers marks every result that has a kernel-checked Lean proof with
small links in the margin. **Lean** opens the proof. **Comparator** opens that result's entry in
the paper's evidence record, one Markdown file per paper in this directory (the two long
records of #249 and #257 are divided by section).

For each result, the record reproduces the printed statement and gives:

- every Lean declaration that states it, quoted from the repository at the pinned commit, with
  a sentence saying how a stronger Lean statement implies the printed one;
- the independent Comparator check, when there is one: the Challenge (the same statement
  written again from Mathlib alone in [plectis-erdos-lean](https://github.com/wcook04/plectis-erdos-lean)),
  the Solution that proves it from our declaration, and the replay report of the run that
  checked it, kept under `comparator/`;
- what the Lean proof assumes, when it assumes an input the printed statement does not.

A Challenge file shows `sorry` because it states the target without proving it; Comparator
checks the Solution against it and allows only the axioms `propext`, `Quot.sound` and
`Classical.choice`. These checks establish that the stated propositions are proved. Whether a
proposition is the right one is for the reader to judge against the paper.

The records, the margin links (`paper/evidence/`) and `paper_evidence.json` are generated by
`scripts/paper_evidence.py` from the coverage ledger `docs/paper_lean_coverage.json`,
`comparator/associations.json`, the replay reports and `relations.json`; do not edit them by
hand. `config.json` pins the corpus commit, the replay run and the commit of the records the
papers link to.
