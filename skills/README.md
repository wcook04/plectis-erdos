# Clone-local agent skills

These skills travel with the public repository. They describe bounded workflows
that an agent can execute using only tracked files in this clone.

- [Erdős research return](erdos-research-return/SKILL.md): prepare, validate,
  assimilate, and credit a public research contribution without depending on a
  private repository.
- [Public mathematical writing](public-mathematical-writing/SKILL.md): write
  reader-facing mathematics as prose while preserving exact evidence and open
  boundaries; keep commands and schemas in the agent layer.
