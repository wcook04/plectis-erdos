## Source-grounded design choices

The private annex preserves the downloaded primary documents and version
identities. Public citations point to those documents directly, without making
the public repository depend on private custody paths.

- Aletheia's evaluation separates validity from intended meaning. Of 200
  adjudicated candidates, 63 were technically correct and 13 meaningfully
  addressed the intended questions; the other 50 used unintended readings.
  This motivates explicit statement-relation review, without transferring that
  study's error rate to Plectis. [Feng et al., v1, §1.1 and Table 2](https://arxiv.org/html/2601.22401v1).
- LeanArchitect derives blueprint information from annotated Lean source.
  It is prior art for source-owned navigation; extracting a dependency or
  declaration is a different operation from checking correspondence with an
  informal claim. [LeanArchitect, v1](https://arxiv.org/html/2601.22554v1).
- ScienceAgentBench evaluates publication-derived scientific coding tasks with
  executable outputs and task-specific evaluation. It informs the use of
  frozen tasks, explicit graders and cost accounting here; its reported scores
  do not measure mathematical reading in this corpus. [ScienceAgentBench, v2](https://arxiv.org/html/2410.05080v2).
- AlphaEvolve's task specifications and evaluators delimit its program-search
  results. A proposed mechanism transfer here likewise needs a declared target,
  baseline, evaluator and disconfirmation condition before an outcome is
  observed. [AlphaEvolve, v1](https://arxiv.org/html/2506.13131v1).

No comparison in this record establishes that the repository is unique, that
its tools improve model performance, or that it has independent users. Those
remain empirical questions with separate evidence requirements.
