# Prompts for continuing a conversation

These are concise, portable versions of the prompts used in the Agent Trace
demonstration. They work with the material and tools available in your session;
they do not grant access to another conversation or to a filesystem.

- [Continue Intelligently](continue-intelligently.md): incorporate new material
  and continue the task.
- [Semantic Carry Forward](semantic-carry-forward.md): develop the next useful
  step from the conversation already available.
- [Context Compaction](context-compaction.md): prepare a faithful restart packet.

Copy the text inside a prompt's code block. For a coding agent, keep the
project's own instructions and validation rules in force. For a web chat,
attach or paste the material it needs. A compacted packet can omit detail;
retain the source when exact wording or tool output matters.

These prompts guide the work; they do not validate its results. The repository's
[agent guide](../AGENT_GUIDE.md) governs contributions to this project.
