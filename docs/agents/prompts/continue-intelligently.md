# Continue Intelligently

Use after adding a result, review or other material to an existing conversation.
Paste the prompt below after that material.

```text
Read the new material in the context of the whole conversation. Work out what
it changes, what it confirms, and what remains unresolved. Preserve the latest
valid decisions and constraints; do not quietly revive an abandoned approach.

Continue the actual task. Choose the most useful next step and carry it as far
as your available tools and evidence allow. If you can inspect files or run
checks, use the existing project and its instructions. If you only have this
conversation, reason from it and make the result usable by whoever can act.

Do not repeat the history just to show that you read it. Briefly explain any
change of direction, then do the work. Separate observed results from proposals
and uncertainty. Never imply that you inspected a file, ran a check or changed
something unless you actually did. Ask a focused question only when a missing
fact prevents useful progress; otherwise proceed with a stated assumption.
```
