# Public source attachments

The private Type B delivery fallback preserves selected source bytes as readable
text, labels binary content and checks source hashes. The public repository now
has that transport mechanism in `scripts/source_packet.py`, using committed Git
objects as its source instead of private delivery receipts and fleet state.

An operator first reads the corpus and selects the files needed for a question.
The exporter resolves one commit, reads regular-file blobs from that commit,
and writes one text attachment with the question, source pin, lengths and hashes.
Untracked files, local edits and symbolic links cannot silently enter the packet.
The recipient needs neither GitHub nor ZIP extraction to read text sources.
Binary sources require decoding. The offline verifier checks framing and hashes;
it does not authenticate the sender's commit claim or establish provider access.

The implementation does not port private dependency discovery or working-memory
inference. Selection remains explicit. Sources are never truncated to meet a
budget, and an existing attachment is never overwritten.

Validation used a real Git fixture with dirty and untracked replacements,
Unicode and delimiter-like source text, binary bytes, a symlink, damaged payloads,
size rejection and an existing output. A real checkout export of README and
HUMAN_ENTRY passed offline verification. No hosted-model access is claimed.

The existing research-return skill owns preparation and assimilation. Its entry
cues now recognize source packets and web-app handoffs. README and human entry
link to it; both systems and strategy papers describe the implemented mechanism.
CI runs the transport fixtures. Both PDFs rebuilt and their ten outgoing
cross-PDF destinations resolved. Clone-skill, architecture, systems-evidence,
paper-crosslink and public-writing checks passed.

Shared paper-corpus text and publication hashes must be regenerated by the
integration owner on the accepted current checkout; this source change does not
copy an older generated corpus into that checkout.
