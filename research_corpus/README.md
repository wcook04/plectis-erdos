# Mathematical research corpus

Use this mathematics to solve the original problems. Each frontier gives the complete
established statements, known failed approaches, remaining obligations and proof-source
links from its committed research packet. Evidence classes and hypotheses matter:
an ordinary proof, a Lean theorem and a numerical experiment provide different guarantees.

[Browse the whole mathematical graph](../docs/semantic/BROWSER.md) to find results and
typed relationships beyond a single problem. These pages work directly on GitHub;
no clone or Python execution is required. The repository's existing
[query tool](../scripts/query_corpus.py) is also available to agents with execution access.
