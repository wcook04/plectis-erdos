# Erdős #1049: primitive q-Apéry tail-denominator arithmetic

## Result

The primitive q-Apéry moving tails have an exact finite arithmetic feature
that the modular-selector scans did not expose.  If

\[
  w_n=(A_n,B_n)\in\mathbb Z^2
\]

is the primitive row generated by the source recurrence and

\[
  M_s=2^{3s^2+3s+1}3^{s+1},
\]

then, for rows through index 255 and every start \(0\le s\le15\),

\[
 \frac{\gcd_{j>s}\det(w_s,w_j)}{M_s}
   =\gcd_{s\le j\le255} B_j.
\]

The full two-coordinate tail gcd is nevertheless one.  Thus the extra index
is directional: it lives entirely in the denominator coordinate, not in a
common scalar content of the primitive lattice.

The first nontrivial tail is

\[
  211\mid B_j\qquad(5\le j\le255),
\]

and the checked tail gcd grows as follows.

| starts | finite tail denominator gcd |
|---|---:|
| 0--4 | 1 |
| 5--6 | 211 |
| 7--8 | \(71\cdot211\) |
| 9--10 | \(71\cdot211\cdot1009\) |
| 11--12 | \(71\cdot211\cdot331\cdot1009\) |
| 13 | previous \(\times53\times29927\) |
| 14 | previous \(\times463\) |
| 15 | previous \(\times3571\) |

Every newly appearing factor in this finite table divides the source denominator
\(3^s-2^s\) at its first checked start.  This makes the phenomenon visibly
source-specific: it is inherited from rational specialization of the
q-recurrence rather than from generic rank-two lattice geometry.

## Source and attribution boundary

The q-Apéry antecedent is Tewodros Amdeberhan and Doron Zeilberger, *q-Apéry
Irrationality Proofs by q-WZ pairs*, Adv. Appl. Math. 20 (1998), 275–283. The
downloaded primary source is retained locally as
`annexes/arxiv-math9804122-amdeberhan-zeilberger-q-apery/source.pdf`, with the
editable source at `source.tex`. Source TeX lines 31–50 define the same
q-harmonic Lambert value, lines 72–95 give the q-WZ form, potential, mollifier,
and summed sequences, lines 97–119 give the shared recurrence, and lines
196–207 state the integer-base decay and Theorem 1. The paper's section 1.7
arithmetic step is the q-product denominator clearing; its theorem assumes an
integer \(|q|>1\).

That primary source does **not** state the primitive rational-specialization rows
at \(q=3/2\), the tail gcd identity, the factor `211`, the displayed loss blocks,
or the moving-window question. Those finite rows, exact gcd comparisons, and
loss-block falsifiers are repository-authored computations. The formal consumer
`QAperyTailDenominator.lean` proves only the stated finite prime-gap and selector
implications from supplied divisibility hypotheses; it does not turn the source's
integer-base theorem into a rational-base irrationality result. In particular,
the finite evidence here supplies no cofinal tail law, asymptotic decay, or proof
of Erdős #1049.

## The earlier fixed-prime persistence reading needs qualification

The row-179 probe suggested an infinite-tail divisor law.  Extending the
*specific falsifier* for the claim that an observed initial block persists
forever, rather than scanning new starts,
shows why that promotion is invalid.  Several primes divide a long initial
block of denominator coordinates and then disappear for one full block whose
length is the order of \(3/2\) modulo the prime:

| prime | order \(s\) | first loss block |
|---:|---:|---:|
| 5 | 2 | 8--9 |
| 19 | 3 | 54--56 |
| 13 | 4 | 48--51 |
| 7 | 6 | 36--41 |
| 29 | 7 | 91--97 |
| 97 | 8 | 88--95 |
| 23 | 11 | 242--252 |

For each completed block in the checked range, divisibility returns at the
next index.  In particular, \(23^2\) belonged to the row-179 tail gcd but is
absent from the row-255 tail gcd.  This refutes the unqualified inference from
an initial finite block to an infinite tail, but it does **not** refute a tail
that begins after a final harmonic loss: the source-specific fixed-prime route
is conditional on an all-level monodromy/5-adic-continuity premise.  The
complementary moving-prime selector remains a finite arithmetic target, not a
proved cofinal law.

## Formal consumer

`QAperyTailDenominator.lean` proves the reusable statement needed by an
irrationality argument.  Let \(\ell\) be prime.  If

\[
  \ell\mid B,\qquad \ell\nmid A,
  \qquad\ell\nmid q,
\]

then

\[
  Ba-Aq\ne0,
  \qquad
  \left|B\frac aq-A\right|\ge\frac1q.
\]

There is also a two-row automatic form.  If \(\ell\) divides both denominator
coordinates but \(\ell^2\) does not divide the exterior determinant, at least
one numerator coordinate is nonzero modulo \(\ell\); hence one of the two
rational remainders has the \(1/q\) gap.  The exact receipt records witnesses
for every checked tail prime occurring to the first power.

This is stronger than merely checking that a computed real remainder is
nonzero.  It turns a source-local determinant valuation into a uniform
certificate against *every* rational target whose denominator avoids the
prime.

The same module also proves the finite-window combinatorial gain.  If all
\(k\) denominator coordinates vanish modulo \(N\), then only the numerator
sum must be pigeonholed, so \(N<2^k\) already gives two distinct binary
selectors with equal sums in both coordinates.  This is the theorem that a
moving finite-window divisor can actually feed; it assumes no infinite-tail
persistence.

## What remains

This does not yet prove Erdős #1049.  The explicit loss blocks show that the
unqualified fixed-tail divisor inference is the wrong target; a later fixed
tail would require the conditional source-specific transfer described above.
The primitive cleared q-Apéry forms measured so far also grow, so a successful
proof still needs an analytic-aware recombination with cofinal decay and
controlled coefficient height.

The next theorem-sized target is therefore precise:

1. analyze the modulo-prime block dynamics and supply, for cofinally many
   starts \(s\), a moving divisor across the exact window of width
   \(3s^2+5s+3\);
2. use the one-coordinate pigeonhole theorem in
   `QAperyTailDenominator.lean`, and retain a prime to the first power in a
   two-row exterior determinant; and
3. prove two recombined forms tend to zero with coefficient height below the
   determinant obstruction already formalized in `TwoSelectorRemainderEscape`.

Computation should now be used only to falsify a proposed formula for step 1
or a proposed uniform inequality for step 3.  Extending the row cutoff alone
would not change the mathematical status.
