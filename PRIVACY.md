# Privacy

This repository is a static scholarly artefact containing Lean sources, a
paper, and release metadata. The repository itself does not run a hosted
service, collect analytics, set cookies, or request personal information.

## GitHub and contributions

GitHub may process account and technical data under its own policies when you
view this repository, clone it, or use its issue and pull-request services.
If you open an issue, pull request, or research-return form, include only the
information needed for the request and do not post passwords, access tokens,
private correspondence, or other sensitive material in a public record.

The repository maintainer uses the information in those records to respond to
the request and maintain the project. GitHub controls the storage and service
operation for those records.

## Security reports

For a sensitive security report, follow the private reporting route in
[`SECURITY.md`](SECURITY.md) instead of posting details publicly.

## Changes

If the repository gains a hosted service or another data-collection feature,
this notice will be updated to describe that change.
