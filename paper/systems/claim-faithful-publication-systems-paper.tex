\section{A support condition through the publication path}\label{sec:predigestion}\label{sec:world}



% SENTENCE r3.007.01a
Consider the series
\[
 X_A(b)=\sum_{a\in A}\frac{1}{b^a-1},
 \qquad A\subseteq\mathbb N_{>0}\text{ infinite},\quad b\in\mathbb Z,\ b\ge2.
\]
% END SENTENCE r3.007.01a
% SENTENCE r3.007.01b
For a finite nonempty set $P$ of primes, write
$h_P(a)=\prod_{p\in P}p^{v_p(a)}$ for the $P$-part of $a$.
% END SENTENCE r3.007.01b
% SENTENCE r3.007.02
The weighted support theorem in the Problem~257 paper~\cite{paper257} states that
\begin{equation}\label{eq:worked-condition}
 \sum_{a\in A}\frac{h_P(a)}{a(2^{h_P(a)}-1)}<\infty
\end{equation}
implies that $X_B(b)$ is irrational for every integer $b\ge2$ and every infinite subset $B\subseteq A$.
% END SENTENCE r3.007.02
% SENTENCE r3.007.03
The quantifiers over $b$ and $B$ belong to the conclusion; the summability condition belongs to the hypothesis.
% END SENTENCE r3.007.03
% SENTENCE r3.008.01
For $P=\{2\}$, write $a=2^km$ with $m$ odd.
% END SENTENCE r3.008.01
% SENTENCE r3.008.02
The summand in~\eqref{eq:worked-condition} becomes $1/[m(2^{2^k}-1)]$: the large power of two allows a support with more reciprocal mass than the unweighted criterion would permit.
% END SENTENCE r3.008.02
% SENTENCE r3.008.03
For example, $A=\{2^k:k\ge0\}$ satisfies the condition since $2^{2^k}-1\ge2^k$, and hence the summands are at most $2^{-k}$.
% END SENTENCE r3.008.03
% SENTENCE r3.008.04
Every infinite thinning of this support satisfies it as well.
% END SENTENCE r3.008.04


% SENTENCE r3.009.01
To see how the proof works, consider the displacement
\begin{equation}\label{eq:worked-displacement}
 \Delta_{b,A}(N)=\sum_{a\in A}\frac{b^{N\bmod a}-1}{b^a-1}
               =(b^N-1)X_A(b)-J_{b,A}(N),
\end{equation}
where $J_{b,A}(N)=\sum_{a\in A,\,a\le N}\sum_{j=1}^{\lfloor N/a\rfloor}b^{N-ja}$ is an integer.
% END SENTENCE r3.009.01
% SENTENCE r3.009.02
For $N>0$, an exponent $a>N$ contributes a positive term, so rationality $X_A(b)=p/q$ would imply $\Delta_{b,A}(N)\ge1/q$.
% END SENTENCE r3.009.02
% SENTENCE r3.009.03
The proof contradicts this lower bound by averaging along multiples of a growing modulus.
% END SENTENCE r3.009.03
% SENTENCE r3.009.04
The difficult estimate concerns incomplete periods: a complete-period average alone does not control the finite tails needed in the argument, so the weighted proof takes a second, dyadic average~\cite{paper257}.
% END SENTENCE r3.009.04


% SENTENCE r3.010.01
Erd\H{o}s had already stated the reciprocal-summable support criterion~\cite{erdos1968}.
% END SENTENCE r3.010.01
% SENTENCE r3.010.02
The Problem~257 paper supplies its averaging proof and distinguishes the weighted extension from that earlier statement.
% END SENTENCE r3.010.02
% SENTENCE r3.010.03
It also compares perfect-power supports with the Lambert-series work of Duverney and Tachiya~\cite{duverneytachiya}.
% END SENTENCE r3.010.03
% SENTENCE r3.010.04
These attributions must travel with the argument: a new arrangement of a proof does not make its ingredients new.
% END SENTENCE r3.010.04


% SENTENCE r3.011.01
The universal question asks for irrationality for every infinite $A$ in base two.
% END SENTENCE r3.011.01
% SENTENCE r3.011.02
For each finite $P$, full support, the odd exponents and the primes all fail~\eqref{eq:worked-condition}; the theorem gives no rationality conclusion for them~\cite{paper257}.
% END SENTENCE r3.011.02
% SENTENCE r3.011.03
Thus an abstract that drops the support condition asserts more than the theorem proves, even if its Lean links remain intact.
% END SENTENCE r3.011.03


% SENTENCE r3.012.01
In a writer's dossier, we keep the exact statement beside its evidence and the remaining universal question.
% END SENTENCE r3.012.01
% SENTENCE r3.012.02
Fields for the mechanism and the difficult step may be empty: their content has to come from an argument such as~\eqref{eq:worked-displacement}, rather than from counting the theorem's dependencies.
% END SENTENCE r3.012.02

% END SENTENCE r3.013.01

% END SENTENCE r3.013.03

% END SENTENCE r3.014.01

\subsection{A paired protocol}\label{sec:evaluation}


% SENTENCE r3.044.01
The proposed comparison pairs ordinary research sessions on the same task, source revision, evidence limits and effort budget.
% END SENTENCE r3.044.01
% SENTENCE r3.044.02

% END SENTENCE r3.044.02
% SENTENCE r3.044.03
Changing exactly one permitted file is mechanically checkable.
% END SENTENCE r3.044.03
% SENTENCE r3.044.04
Whether that file changes only the intended intervention requires inspection of its content.
% END SENTENCE r3.044.04
% SENTENCE r3.045.01
A separate grader receives anonymised returns in counterbalanced order, with a frozen rubric and answer key but neither the arm label nor the desired outcome.
% END SENTENCE r3.045.01
% SENTENCE r3.045.02

% END SENTENCE r3.045.02
% SENTENCE r3.045.03

% END SENTENCE r3.045.03

% END SENTENCE r3.046.01
% SENTENCE r3.046.02

% END SENTENCE r3.046.02
% SENTENCE r3.046.03
Historical grading by one analyst remains calibration material.
% END SENTENCE r3.046.03
