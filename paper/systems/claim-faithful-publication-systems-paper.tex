\section{One theorem, end to end}\label{sec:example}\label{sec:predigestion}
% SENTENCE r4.example1.01
For an infinite set $A$ of positive integers and an integer $b\ge2$, write $X_A(b)=\sum_{a\in A}(b^a-1)^{-1}$.
% END SENTENCE r4.example1.01
% SENTENCE r4.example1.02
Given a finite nonempty set $P$ of primes, let $h_P(a)=\prod_{p\in P}p^{v_p(a)}$ be the part of $a$ supported on those primes.
% END SENTENCE r4.example1.02
% SENTENCE r4.example1.03
The weighted-support theorem of the Problem~257 paper states that, if
\begin{equation}\label{eq:worked-condition}
 W_{2,P}(A):=\sum_{a\in A}\frac{h_P(a)}{a(2^{h_P(a)}-1)}<\infty,
\end{equation}
then $X_B(b)$ is irrational for every integer $b\ge2$ and every infinite $B\subseteq A$~\cite[Theorem~1.2]{paper257}.
% END SENTENCE r4.example1.03
% SENTENCE r4.example1.04
The paper also gives a fixed-base version with $2$ replaced by $b$ in the hypothesis; the recorded Lean support for both clauses is shown in Figure~\ref{fig:theorem}.
% END SENTENCE r4.example1.04
% SENTENCE r4.example1.05
The arbitrary infinite-support question in base two remains open.
% END SENTENCE r4.example1.05

% SENTENCE r4.example2.01
Erd\H{o}s had already stated that $\sum_{a\in A}1/a<\infty$ suffices for this all-base irrationality conclusion~\cite[p.~222]{erdos1968}.
% END SENTENCE r4.example2.01
% SENTENCE r4.example2.02
The corresponding formal declaration is \repolink{lean/Erdos249257/AllBaseReciprocalSupportIrrationality.lean}{irrational\_erdosSupportSeries\_}\allowbreak\repolink{lean/Erdos249257/AllBaseReciprocalSupportIrrationality.lean}{of\_summable\_reciprocal}, with Comparator entry \texttt{PalomarCorpus/E257av} recorded as compared.
% END SENTENCE r4.example2.02
% SENTENCE r4.example2.03
The source paper credits Duverney and Tachiya for an arithmetic-progression averaging argument of the kind used to select a small positive displacement~\cite[Section~2, (2.3)--(2.9)]{duverneytachiya}.
% END SENTENCE r4.example2.03

% SENTENCE r4.example3.01
To see what the weighted hypothesis adds, consider the source paper\textquotesingle s calculation
\[
 A_\star=\{2^km:k\ge1,\ m\text{ odd},\ 1\le m\le2^{2^k}\},\qquad P=\{2\}.
\]
% END SENTENCE r4.example3.01
% SENTENCE r4.example3.02
Put $S_r=\sum_{1\le m\le2^r,\ m\ \mathrm{odd}}1/m$; grouping the odd integers into intervals $[2^j,2^{j+1})$ gives $r/4\le S_r\le r$ for integers $r\ge2$.
% END SENTENCE r4.example3.02
% SENTENCE r4.example3.03
The disjoint layer with $v_2(a)=k$ therefore contributes at least $2^{-k}S_{2^k}\ge1/4$ to the reciprocal sum, whereas its weighted contribution is at most
\[
 \frac{S_{2^k}}{2^{2^k}-1}\le\frac{2^k}{2^{2^k}-1}\le2^{1-k}.
\]
% END SENTENCE r4.example3.03
% SENTENCE r4.example3.04
Thus $\sum_{a\in A_\star}1/a$ diverges but $W_{2,\{2\}}(A_\star)$ converges; this calculation is supplied in the paper\textquotesingle s example and has no separate Lean-ledger row~\cite[calculation following the weighted proof]{paper257}.
% END SENTENCE r4.example3.04

% SENTENCE r4.example4.01
The proof uses the nonnegative displacement
\begin{equation}\label{eq:worked-displacement}
 \Delta_{b,A}(N)=\sum_{a\in A}\frac{b^{N\bmod a}-1}{b^a-1}
 =(b^N-1)X_A(b)-J_{b,A}(N),\qquad N\ge1,
\end{equation}
where the finite sum $J_{b,A}(N)=\sum_{a\in A,\,a\le N}\sum_{j=1}^{\lfloor N/a\rfloor}b^{N-ja}$ is an integer.
% END SENTENCE r4.example4.01
% SENTENCE r4.example4.02
If $X_A(b)=p/q$ with $q>0$, then $\Delta_{b,A}(N)>0$, because $A$ contains an exponent larger than $N$, and integrality in~\eqref{eq:worked-displacement} gives $\Delta_{b,A}(N)\ge1/q$.
% END SENTENCE r4.example4.02

% SENTENCE r4.example4.03
We seek a multiple $N=tQ$ at which this displacement is smaller.
% END SENTENCE r4.example4.03
% SENTENCE r4.example4.04
A finite part of $A$ accounts for all but an arbitrarily small weighted tail, and taking $Q$ divisible by that finite part makes its displacement terms vanish.
% END SENTENCE r4.example4.04
% SENTENCE r4.example4.05
Enlarging $Q$ by suitable powers of the primes in $P$ controls the orbit averages of the other terms through $\gcd(a,Q)$.
% END SENTENCE r4.example4.05

% SENTENCE r4.example4.06
The difficulty is that a finite average usually ends partway through an orbit: bounds for those incomplete periods need not sum over all exponents.
% END SENTENCE r4.example4.06
% SENTENCE r4.example4.07
The source proof takes a second average over lengths $2^j$, with $M\le j<2M$, choosing $M$ large relative to the polynomial size of $Q$ and small relative to the exponential orbit saving.
% END SENTENCE r4.example4.07
% SENTENCE r4.example4.08
Both boundary errors then tend to zero, so one term contradicts the rational lower bound; the weighted sum decreases on passing to $B\subseteq A$, and $b^{h_P(a)}-1\ge2^{h_P(a)}-1$ transfers the binary hypothesis to every $b\ge2$~\cite[Section~2]{paper257}.
% END SENTENCE r4.example4.08
